<AccordionGroup>
  <Accordion title="What is AgentMail?">
    AgentMail gives your agents email inboxes through an API. They can send and receive messages, work with attachments, and keep replies in threads. Start with the [introduction](/introduction) or [create your first inbox](/quickstart).
  </Accordion>
  <Accordion title="How is AgentMail different from a transactional email service?">
    AgentMail supports conversations in both directions. Inboxes, messages, threads, and drafts let an agent receive an email, inspect its history, and send a reply. See [the architecture](/architecture).
  </Accordion>
  <Accordion title="Can I send email from my own domain?">
    Yes. Register the domain, add the returned DNS records, and verify it before creating inboxes on it. Follow the [custom domain guide](/advanced/custom-domains).
  </Accordion>
  <Accordion title="How should I process incoming email?">
    Use [webhooks](/advanced/webhooks) to receive events at an HTTPS endpoint, [WebSockets](/advanced/websockets) for a persistent connection, or [poll for messages](/core/receive). The receive guide explains how to fetch the full message and its attachments.
  </Accordion>
  <Accordion title="How do I get only the new text from a reply?">
    Use `extracted_text` or `extracted_html` from the full message. These fields remove quoted history. See [reading one message in full](/core/receive#read-one-message-in-full).
  </Accordion>
  <Accordion title="How do I keep messages out of spam?">
    Set up domain authentication, check delivery failures, and build sending volume gradually. Follow the [deliverability guide](/advanced/deliverability) and [email authentication reference](/extras/deliverability-fundamentals).
  </Accordion>
  <Accordion title="Are SDKs available?">
    See [SDKs and CLI](/integrations/sdks-and-cli) for installation and usage, and the [API reference](/api-reference/inboxes/list-inboxes) for individual endpoints.
  </Accordion>
</AccordionGroup>
